# 기본 법칙

- 개발 언어는 `python`이다.
    - `python`의 버전은 3.10 이상이어야 한다
    - `Flet` 1.0 패키지만 사용 가능하다
    - `random` `json`등의 모듈은 사용 가능하다
- `Flet`은 `main.py`와 동일한 뼈대를 기반으로 작성해야한다
    - 뼈대에 없는 클래스, 인자, 속성은 사용하지 않는다
    - 메모리에 저장된 Flet 문법은 버전이 맞지 않으므로 절대 사용하지 않아야만 한다
    - 특히 flet 1.0에서 절대 사용하면 안되는 존재하지 않는 함수는 다음과 같다
        - ft.app(...)
        - ft.colors
        - ft.alignment.center
        - ft.ElevatedButton
        - Button(text=...)
        - page.window_width
        - ft.UserControl
        - TextField(error_text=...)



# 작업 개요

입차 시각과 출차 시각을 넣으면 요금을 계산해 목록에 쌓고, 오늘 받은 요금의 합계를 보여 주는 창 하나짜리 프로그램을 만듭니다.

## 기본 요구사항
- 시각은 09:30처럼 24시간제 "시:분"으로 입력한다. 출차는 입차보다 뒤여야 한다.
- 요금은 30분까지 무료, 이후 10분마다 500원이다. 10분이 안 되는 나머지도 10분으로 센다. 하루 최대 요금은 20,000원이다.
- 계산할 때마다 입차, 출차, 주차 시간, 요금을 목록에 쌓는다. 목록의 각 줄에는 삭제 버튼이 있고, 지우면 합계를 다시 계산한다.
- 금액은 천 단위마다 쉼표를 넣어 보여 준다.

요구사항에 없는 것은 자유롭게 정합니다. 잘못된 시각, 자정을 넘기는 주차, 빈 입력을 어떻게 할지가 여기에 들어갑니다.

# 주차 요금 계산기 스펙 문서

## 1. 기본 개요
- **목적**: 입차 시각과 출차 시각을 입력받아 주차 요금을 계산하고 기록을 관리하는 프로그램.
- **언어/프레임워크**: Python 3.10+, Flet 1.0.

## 2. 동작 규칙 (Business Logic)

### 2.1 시간 입력 규칙
- **형식**: 24시간제 `"HH:MM"` (예: `09:30`, `22:15`).
- **유효성**: 
    - 반드시 `HH:MM` 형식을 지켜야 함.
    - **출차 시각은 반드시 입차 시각보다 뒤여야 함**.

### 2.2 요금 계산 규칙
- **무료 구간**: 주차 시간이 **30분 이하**인 경우 요금은 **0원**.
- **유료 구간**: 30분을 초과하는 시점부터 적용.
    - **단위**: 10분 단위로 과금.
    - **올림 적용**: 10분 미만의 잔여 시간도 10분으로 간주하여 올림 처리.
    - **단가**: 10분당 **500원**.
- **최대 요금**: 하루 최대 요금은 **20,000원**을 초과할 수 없음.

### 2.3 출력 및 기록 규칙
- **표시 형식**: 금액은 천 단위마다 쉼표(`,`)를 사용하여 표시 (예: `1,500원`).
- **목록 관리**:
    - 계산된 각 기록은 [입차, 출차, 주차 시간, 요금]을 포함하여 리스트에 누적.
    - 각 기록 옆에는 **삭제 버튼**이 있으며, 삭제 시 해당 항목이 제거되고 전체 합계가 즉시 재계산됨.
