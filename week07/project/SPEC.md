# 기본 규칙

- 개발 언어는 `python`이다.
    - `python`의 버전은 3.10 이상이어야 한다
    - `Flet` 1.0 패키지만 사용 가능하다
    - `random` `json`등의 모듈은 사용 가능하다
- `Flet`은 `main.py`와 동일한 뼈대를 기반으로 작성해야한다
    - 뼈대에 없는 클래스, 인자, 속성은 사용하지 않는다
    - 메모리에 저장된 Flet 문법은 버전이 맞지 않으므로 절대 사용하지 않아야만 한다
    - 특히 flet 1.0에서 절대 사용하면 안되는 존재하지 않는 함수는 다음과 같다
        - ft.app(...)
        - ft.colors
        - ft.alignment.center
        - ft.ElevatedButton
        - Button(text=...)
        - page.window_width
        - ft.UserControl
        - TextField(error_text=...)

## 개발

### 과제1. 단위 변환기
값과 단위를 넣으면 다른 단위로 바꿔 보여 줍니다.

요구사항

단위는 길이(mm, cm, m, km)와 온도(°C, °F)다. 두 단위 목록에 여섯 개가 모두 들어 있다.
길이와 온도를 섞어 고르면 변환하지 않고 안내 문구를 보여 준다.
숫자가 아닌 값을 넣으면 결과 칸을 비우고 안내 문구를 보여 준다.

#### 개발계획

1. **함수 인터페이스**
   - `convert(value_str, from_unit, to_unit)` 함수를 `logic.py`에 구현한다.
   - 반환값은 `(result_value, notice_message)` 형태의 튜플로 하여 GUI와 연동하기 쉽게 한다.

2. **입력값 검증 및 예외 처리 로직**
   - **숫자 유효성 검사**:
     - 입력받은 `value_str`이 `float`으로 변환 가능한지 확인한다.
     - 실패 시: `result_value = ''`, `notice_message = '숫자를 입력해주세요'` 반환.
   - **단위 호환성 검사**:
     - 입력된 `from_unit`과 `to_unit`이 동일한 그룹(길이 그룹: `mm, cm, m, km` / 온도 그룹: `°C, °F`)에 속하는지 확인한다.
     - 그룹이 다를 경우(예: `m` -> `°C`): `result_value = ''`, `notice_message = '길이와 온도는 변환할 수 없습니다'` 반환.

3. **정상 변환 케이스 (허용 범위)**
   - **길이 변환**: `mm, cm, m, km` 사이의 모든 조합 지원 (예: `1m` -> `100cm`).
   - **온도 변환**: `°C` <-> `°F` 변환 지원 (예: `0°C` -> `32°F`).

4. **테스트 전략**
   - `test_logic.py`에서 `unittest`를 사용하여 위 2번 항목의 모든 예외 케이스를 포함한 테스트 코드를 작성한다.
   - 정상 케이스에 대해서도 소수점 오차 범위를 고려한 검증을 수행한다.


### 과제 2. 숫자 맞히기
숫자 맞히기 화면

프로그램이 1부터 100 사이의 숫자를 하나 정하고, 사용자가 맞힐 때까지 "더 큽니다", "더 작습니다"로 알려 줍니다.

요구사항

- 범위는 1부터 100이고 정답은 무작위다.
- 시도할 때마다 입력한 숫자와 판정을 목록에 쌓고 시도 횟수를 보여 준다.
- 맞히면 몇 번 만에 맞혔는지 보여 주고, 새 게임 버튼을 누르기 전에는 더 입력받지 않는다.


### 과제 3. 학점 계산기
학점 계산기 화면

```
Row(TextField(과목명) Dropdown(학점) Dropdown(성적) Botton(추가))

여러줄의 readonly TextField - 최소 10줄
과목명 | n학점 | B+ | [삭제]


총 n학점
평점
```



과목 이름, 학점 수, 성적을 넣어 목록에 쌓고, 총 학점과 평점을 보여 줍니다.

요구사항

- 성적은 A+, A0, B+, B0, C+, C0, D+, D0, F이고 점수는 4.5, 4.0, 3.5, 3.0, 2.5, 2.0, 1.5, 1.0, 0이다.
- 학점 수는 1, 2, 3 중에서 고른다.
- 평점은 (성적 점수 × 학점 수)의 합을 학점 수의 합으로 나눈 값이다. 과목을 지우면 다시 계산한다.


### 과제 4. 비밀번호 생성기
비밀번호 생성기 화면

```
TextField(길이)
Row(CheckBox(대문자 포함) CheckBox(숫자 포함))
CheckBox(특수문자 포함)
Botton(만들기)

한줄의 readonly TextField - 최소 10줄
Botton(만들기)

Text(길이가 4보다 작으면 안내문구)
```

길이와 포함할 문자 종류를 고르면 무작위 비밀번호를 만들어 보여 줍니다.

요구사항

- 소문자는 항상 들어간다. 대문자, 숫자, 특수문자(!@#$%^&*)는 체크 상자로 고른다.
- 길이는 4 이상 32 이하다. 벗어나면 만들지 않고 안내 문구를 보여 준다.
- 체크한 종류의 문자는 적어도 하나씩 들어간다.


### 과제 5. 용돈 기입장
용돈 기입장 화면

```
Row(TextField(내용) TextField(금액) Dropdown(구분))
Botton(추가)

여러줄의 readonly TextField - 최소 10줄
내용 | 구분 | 금액 | [삭제]


수입 n | 지출 m
잔액 k원
```

내용, 금액, 수입과 지출 구분을 넣어 목록에 쌓고, 수입 합계, 지출 합계, 잔액을 보여 줍니다.

요구사항

- 구분은 수입과 지출 두 가지다.
- 금액은 0보다 큰 정수다. 아니면 추가하지 않고 안내 문구를 보여 준다.
- 목록의 각 줄에 삭제 버튼이 있다. 지우면 합계와 잔액을 다시 계산한다.
- 금액은 천 단위마다 쉼표를 넣어 보여 준다.
